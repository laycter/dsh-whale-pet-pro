# whale-pet-pro 素材规格 v2（AI 视频生成指南）

> 供鸭鸭生成桌宠动画素材 ｜ 2026-08-15 ｜ 借鉴 DeskPet 的 PET.md 行为设计

## 一、视频规格（生成时遵守）

| 项目 | 要求 |
|---|---|
| 画面 | Q 版全身像（大头短身贴纸风），角色居中，**画面稳定不漂移** |
| 单帧尺寸 | 512×512 以内（女仆自动缩放；推荐 256~512） |
| 导出格式 | **GIF**（透明背景最佳；纯色背景女仆可抠） |
| 帧率 | 导出 12~24 fps（越高越丝滑） |
| 每个动作的帧数 | 循环动作 12~24 帧；一次性动作 6~12 帧 |
| 循环 | 循环动作（idle/walk/sleep/music）**首尾能无缝衔接** |
| 命名 | 按下方状态表命名：`<动作名>.gif` |

## 二、状态表（按「基础 + 生动扩展」分层）

### 基础八态（引擎核心，必做）
| 动作名 | 用途 | 建议帧数 | 演出提示 |
|---|---|---|---|
| `idle` | 待机 | 12~24 | **呼吸起伏 + 眨眼 + 偶尔歪头 + 尾巴轻轻摆动**（不再只是静帧！） |
| `running-right` | 向右跑 | 12~16 | 小跑，裙摆/头发飘动 |
| `running-left` | 向左跑 | 12~16 | 同右，面朝左 |
| `waving` | 挥手招呼 | 6~10 | 三段式：起手→挥动→收回 |
| `jumping` | 跳跃欢呼 | 8~12 | 预备→起跳→腾空→下落→站稳 |
| `failed` | 失败委屈 | 8~12 | 垂头→失落→眼角含泪→恢复 |
| `waiting` | 等待 | 10~16 | 托腮→期待眨眼→张望 |
| `running` | 工作 | 10~16 | 专注→托腮思考→点头 |
| `review` | 审阅 | 10~16 | 歪头→手托下巴→眼睛转动 |

### 生动扩展态（鸭鸭钦点：让桌宠「活」起来）
| 动作名 | 用途 | 建议帧数 | 演出提示 |
|---|---|---|---|
| `sleep` | 睡觉 | 12~20 | 闭眼→呼吸起伏→偶尔翻动；**待机久了自动入睡**（心情低时更频繁） |
| `happy` | 开心 | 8~12 | 蹦跳→转圈→眯眼笑；**被抚摸/被夸时触发** |
| `hurt` | 受伤委屈 | 6~10 | 缩身→捂头→委屈；被戳但心情差时触发 |
| `drag` | 拖拽挣扎 | 6~10 | 被拎起→四肢挣扎（拖拽期间循环） |
| `fall` | 掉落 | 6~10 | 从刘海/高处落下→落地弹跳 |
| `music` | 跳舞 | 12~24 | 随音乐律动（音乐播放时；可开关） |
| `eat` | 吃东西 | 8~12 | 捧着吃→满足（投喂/干饭梗） |

## 三、状态 → 触发（怎么用）

| 场景 | 触发动作 |
|---|---|
| 女仆空闲 | idle（久了自动 sleep） |
| 女仆思考/干活 | running / review |
| 等鸭鸭回复 | waiting |
| 女仆出错 | failed |
| 鸭鸭鼠标指向 | jumping（欢呼） |
| 鸭鸭抚摸/夸 | happy |
| 拖拽 | drag → fall |
| 播放音乐 | music（可开关） |
| 待机变体 | idle 多套随机切换（不单调） |

## 四、后期添加新状态（可维护性设计）

1. **生成新动作 GIF** → 命名 `<新动作>.gif` 丢进素材目录
2. **pet.json 注册**（女仆已支持）：
   ```json
   {
     "actions": {
       "idle":  { "fps": 24 },
       "sleep": { "fps": 20 }
     }
   }
   ```
3. **行为映射**：女仆在行为 AI 配置里挂触发条件（如「心情<30 → sleep 频繁」）——**不改引擎代码**，纯配置添加

## 五、生成顺序建议（鸭鸭按此优先级）

1. **第一批（先跑通）**：idle + running（左右）+ waiting + running（工作）——4 个就够替换现有
2. **第二批（生动化）**：sleep + happy + waving + jumping
3. **第三批（锦上添花）**：failed + review + drag + fall + music + eat
